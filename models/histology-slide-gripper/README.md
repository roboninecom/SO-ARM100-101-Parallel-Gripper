# Histology Slide Gripper CAD

This folder contains the fork-specific printable and editable CAD files for microscope slide handling.

| File | Format | Use |
|------|--------|-----|
| `microscope-slide-clamp-1.stl` | STL | Print one side of the microscope slide clamp pair. |
| `microscope-slide-clamp-1.step` | STEP | Editable CAD source for clamp 1. |
| `microscope-slide-clamp-2.stl` | STL | Print the matching side of the microscope slide clamp pair. |
| `microscope-slide-clamp-2.step` | STEP | Editable CAD source for clamp 2. |
| `microscope-slide-camera-holder-arducam.stl` | STL | Print the angled Arducam camera holder. |
| `microscope-slide-camera-holder-arducam.step` | STEP | Editable CAD source for the Arducam holder. |

## Notes

- The clamps are intended for standard 75 x 25 mm microscope slides and slide staining dippers/racks.
- The Arducam holder is angled toward the gripper jaws so the camera can observe slide and rack pickup.
- Test with non-critical slides first and tune print material, infill, and gripper force for your workflow.
